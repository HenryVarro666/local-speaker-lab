# 路线图与验证状态

当前主要工作是单人普通话与英文混合听写的固定词表实验。双人语音分离、转写和纪要保留既有 Ubuntu 路线。实现范围与实测证据分别维护；具体协议和结果以[实验说明](../experiments/glossary/README.md)及对应完整运行记录为准。

## 已实现

| 能力 | 当前实现 |
| --- | --- |
| 单人三组对照 | `speaker_lab.glossary_experiment` 的 `check`、`run`、`score`；固定词表、相同音频、原始预测和哈希记录 |
| 训练词表与固定抽样 | 训练文本导出、冻结通用提取规则、独立无关词表、语言分层及固定哈希抽样；[200 条协议](../experiments/glossary/protocols/ascend-val200-train-vocab30-v2/)保留可审阅输入 |
| 轻量计分与比较分析 | 标准库主计分、参考术语转移、按参考位置锚定的错误提及、覆盖分组，以及按语言分层的配对片段 bootstrap |
| 双人处理 | 分段、重叠分离、人物匹配、Qwen 转写与可选强制对齐、Ollama 引用纪要、CLI/Gradio |
| Ubuntu 部署工具 | 独立模型环境、依赖快照、诊断、交互升级与真实录音验收入口；见[部署说明](../DEPLOYMENT.md) |

## 下一步

1. 先审阅 200 条报告中的 5 次术语漏识及新增替换，区分严格拼写／分词差异与声学错误；保留现有主分数和原始预测。
2. 根据本轮结论决定是否扩大固定 validation 或设计下一份独立协议。扩大样本、改变词表或替换模型时保留单独版本，继续隔离训练规则与验证答案；不自动扩样。
3. 在目标 Ubuntu/GPU 机器上完成双人真实录音验收，并逐项记录安装、人物归属、分离、时间戳和纪要的实际表现。
4. 随使用需求逐步整理模块接口、配置和测试，保持当前命令入口与已有实验可复核。任何进一步拆包都作为后续实现变更处理。
