# 实验入口

主流程面向双人录音归轨、转写和纪要。实验保留独立目录，避免把数据准备、评测和个人配置混入默认应用流程。

## 个人术语词表

单人普通话与英文混合听写的独立实验见 [个人术语词表实验](../experiments/glossary/README.md)：复用 Qwen3-ASR，对比无词表、个人词表与无关词表，包含 ASCEND 数据准备和配对计分入口。

该目录的 README 是实验命令和评测协议的权威入口；个人录音、个人词表和数据集不进入源 ZIP。模型对照应固定录音、ASR 和分段配置，每次只换一个因素，记录文字错误、人物归属、耗时与峰值显存。

## 双人录音开发

双人实验从 [模型后端](model-backends.md)选择已有路线或替换适配器，按 [验证与限制](verification.md)评估实际音质与归属。环境、缓存、结果文件和命名规则见 [架构](architecture.md)。
