# Deletion-retention study design

2026-10-20 America/Chicago. The frozen [protocol](../../DELETION_PROTOCOL.md) and pre-test [dev batching addendum](../../DELETION_EVAL_ADDENDUM.md) are authoritative. This report concerns offline ASR and training data, not streaming, TTS, Avatar, deployment or clinical speech.

Nine fresh Qwen3-ASR-0.6B SFTs compare Random CE, deletion-aware selected CE, and the identical selected data with retention-weighted CE, each seeds42/43/44. Every run uses500 examples, epoch1, batch1, gradient accumulation8, learning rate2e-5 and63 optimizer steps; all share the same52 development examples. The selection-only contrast isolates data selection; retention versus selected isolates the objective. The joint contrast alone cannot attribute improvement to either part.

The fixed1015 training candidates use speakers8/9/11/15/19/21. Development combines the previously observed primary40 and challenge12 from speaker5/6 upfront. New test280 uses speaker10/13/14/16/18/24/26,40 per person (zh20/mixed10/en10), chosen from new recordings without seeing model output. Previous continuation, multiseed, coverage, disfluency and old20 recordings are excluded by ID/file/PCM. These are seven IDs in the current isolated split, not seven project-never-seen people; historical training-text glossary exposure and unknown pretraining/session provenance remain limitations.

The selector keeps every previous language-duration, speaker, difficulty, filler presence/frequency/count, repetition/count, switch/span marginal. It also matches per-language base deletion-count bins, tail-deletion presence and source-UNK presence, with audio within1% of Random. Costs are (S+I+0.5D)/N from ONLY train base outputs. This preserves deletion-risk examples while still preferring source agreement; it is neither human quality annotation nor guaranteed optimal curation for unseen speech.

Retention CE boosts eligible subwords2× when their offsets intersect a train reference token that the base deletes across every minimum-edit path, or an adjacent repeated1–4-token motif. Source-UNK spans, digits, standalone ASCII letters and uppercase ASCII words are not boosted; all original targets remain supervised. Header/EOS weight1, masked prompt/padding weight0. The mean divides by valid weight sum per example, then normal Trainer accumulation applies. A subword may cover neighboring characters. Repetition includes genuine lexical reduplication. This is a heuristic training objective, not direct differentiable deletion-rate optimization. The objective contrast includes the explicitly normalized custom CE/Trainer accumulation path as well as2× token weights; it does not isolate the multiplier alone.

Every tokenizer suffix is checked against the actual processor labels; no tokenizer patch, target rewrite or source-reference correction is applied. The cached tokenizer emits an existing regex warning; the same pinned tokenizer remains across all arms, and500 actual processor-suffix checks passed before training. Unreviewed tokenizer changes would be a separate experiment.

Source examples/steps/hyperparameters and approximately audio time match; source reference tokens, BPE counts and FLOPs need not. Different CE values are not directly comparable training-quality scores. A pre-test failure reproduced upstream batched dev label leakage. All final arms use eval batch1; the two initial completed runs and one partial weighted run are archived/excluded, then all nine restart. All nine dev reloads complete before new-test inference. No outcome-driven candidate, seed or checkpoint choice is allowed.

Strict MER and references are unchanged. Report S/D/I, D/N, filler/short-letter/other deletion proxies, repeat/frequency/switch/language groups and stable reference positions. Three contrasts use5000 paired crossed training-seed/whole-speaker bootstrap draws, seed20261020. Three comparisons are exploratory without multiplicity adjustment. A deletion-to-substitution trade is not a verified content-retention improvement. Private playback preserves the original audio and all three arms/seeds; human listening remains pending.
